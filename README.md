# Running Insights

A personal project for exploring and analyzing running data exported from Garmin Connect.

## Project status

The repository currently contains the project shell only. No Garmin exports or analysis code have been added yet.

## Data privacy

Garmin activity exports can include health metrics and location or route data. Keep raw and derived personal activity files on your device in `data/`; this directory is ignored by Git. The repository also ignores common Garmin export formats, generated output, and local environment files. A private GitHub repository is still a synced copy, so review files before committing them.

## Planned workspace

- `data/` — local Garmin exports and derived datasets (not tracked)
- `notebooks/` — exploratory analysis
- `src/` — reusable analysis code
- `outputs/` — generated charts and reports (not tracked)

The analysis tools and import workflow can be chosen when the first Garmin dataset is ready.
